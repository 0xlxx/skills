# GLOSSARY.md 格式

`GLOSSARY.md` 是教学工作区的规范语言。所有解释、练习和学习记录都应遵循其术语。构建它本身就是学习的一部分：将一个概念压缩为精炼的定义，是用户理解它的证据。

## 结构

```md
# {主题} 术语表

{一两句话描述本术语表涵盖的主题。}

## 术语

**肌肥大**：
由重复训练中的机械张力和代谢压力驱动的肌肉增长。
_避免说_：增肌、变大

**渐进超负荷**：
随时间系统性地增加对肌肉的需求——通过负荷、容量或强度。
_避免说_：更使劲、升级

**RPE（自觉用力系数）**：
一种 1–10 的自评量表，衡量一组练习感觉有多难，10 表示力竭，8 表示还剩两次的余力。
_避免说_：努力分数、强度评级
```

## 规则

- **仅在用户理解后添加术语。** 术语表是压缩知识的记录，不是用户拿来学习的词典。如果用户刚接触一个概念，等到他们能正确使用后再收录。
- **要有立场。** 当多个词表示同一概念时，选最好的一个，其余列为应避免的别名。这就是语言压缩的方式。
- **定义保持精炼。** 一到两句。定义术语是什么，而不是它做什么或怎么做。
- **在定义中使用术语表自身的术语。** 一个术语一旦进入术语表，就优先在任何地方使用它——包括在其他定义中。这就是为什么复杂术语以后更容易掌握。
- **出现自然聚类时用子标题分组**（如 `## 解剖学`、`## 编程`）。术语内聚时，平铺列表也可以。
- **明确标记歧义。** 如果某个术语在更广泛的领域中用法松散，注明解决方案："在本工作区中，'组'始终指正式组——热身组单独统计。"
- **随理解加深而修订。** 用户第一周写的定义到第六周可能是错的。原地更新，不要留下过时的条目。
