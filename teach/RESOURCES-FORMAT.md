# RESOURCES.md 格式

`RESOURCES.md` 是针对本主题精心筛选的可信来源集合。解释中的知识应从此处获取，而非来自参数化猜测。智慧来自此处列出的社区。

## 结构

```md
# {主题} 资源

## 知识

- [书籍：《力量训练的科学与实践》——Zatsiorsky & Kraemer](https://example.com)
  关于训练规划和适应的基础教材。用于：任何与周期化、恢复、强度区间相关的内容。
- [文章："我应该练多少？"——Greg Nuckols（Stronger By Science）](https://example.com)
  关于容量基准的循证综述。用于：每个肌群的每周组数目标。

## 智慧（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信号 subreddit，严格管理排除伪科学。用于：训练计划评审、瓶颈排查。
- 线下：{某健身房}周二力量课
  用于：举重动作的实时教练反馈。
```

## 规则

- **仅高信任度。** 偏好一手来源、公认专家、同行评审成果以及有强管理的社区。如果一个资源是伪装成教育的营销，就别放进来。
- **为每个条目添加注释。** 一个裸链接三个月后毫无用处。加一行：涵盖什么内容，什么时候去查阅。
- **按知识/智慧分组。** 体现 [SKILL.md](./SKILL.md) 中的哲学。一个资源只出现在一个组是没问题的。
- **明确暴露缺口。** 如果使命需要的某个领域没有好的资源，写一个 `## 缺口` 栏目列出缺失的内容。这会驱动未来的搜索。
- **无情修剪。** 一个被证明错误、肤浅或偏离使命的资源应该被移除，而不是埋掉。五个精准的来源胜过三十个平庸的。
- **记录社区偏好。** 如果用户选择不加入社区，在此注明，避免未来课程反复提议。
