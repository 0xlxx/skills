# 课程格式

## 核心原则

教学内容 = 多文件 HTML 目录，按本质→逐层→合起来组织。HTML 优先——浏览器原生渲染自带响应式、无障碍、零依赖。

## 前置摸底

用 AskUserQuestion 摸底学生对**本课**前置概念的掌握程度。有不清楚的术语，创建 `prerequisite.html` 做前置科普。

这不同于 SKILL.md 中的最近发展区计算——ZPD 决定"下一课教什么"，前置摸底决定"这一课学生缺哪些先验知识"。两者互补：ZPD 选课，前置摸底补课。

完成标志：已摸底，`prerequisite.html` 已创建或确认不需要。

## 课程生产

### Step 1: 建目录，定原子概念

在 `./lessons/` 下创建 `000N-topic/` 目录。识别构成这个主题的原子概念——每个原子概念完整、独立、不需要上下文就能理解。

```
lessons/000N-topic/
├── prerequisite.html       ← 前置科普（按需）
├── index.html              ← 本质层
├── <concept>.html          ← 原子概念，按概念命名
├── ...
└── <N>-put-together.html   ← 合起来 + 权衡 + 练习
```

一文件一原子概念。文件内不分层——这个 HTML 只管自己这层的概念，更深细节是下一层的事。

完成标志：目录已创建，每个原子概念独立自包含，读者不需要先看别的文件才能理解它。

### Step 2: 写 index.html（本质层）

问题 → 本质概念 → 具体例子。回答：这个东西为什么存在、包含什么、从根本上是什么。问题应来自 MISSION.md。

例子不在多，在于让本质定义从抽象变成可触达。

完成标志：一个完全不了解此概念的人读完后能用一句话说清它是什么、为什么存在。页面首尾有 prev/index/next 导航（index.html 无 prev，put-together 无 next）。

### Step 3: 逐层展开

每个文件：总览 → 逐点展开 → 回连整体。用递阶控制——本级只管本级的原子概念，下一级细节交给后续文件。每一层只比上一层多一层细节，不跳级。

完成标志：每个文件已创建，导航链（prev/index/next）首尾完整可遍历。

### Step 4: 全图

串联所有原子概念，展示它们如何协作。加练习——练习的目的是让用户检验自己是否真正理解了，而不是覆盖所有知识点。加权衡讨论。

完成标志：文件已创建，练习能检验核心理解，权衡讨论点出"什么时候该用、什么时候不该用"。
