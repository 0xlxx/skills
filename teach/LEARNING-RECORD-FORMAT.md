# 学习记录格式

学习记录存放在 `./learning-records/` 中，使用顺序编号：`0001-slug.md`、`0002-slug.md` 等。目录按需创建——仅在写入第一条记录时才创建。

它们是教学版的 ADR：捕获非显而易见的教训、关键洞察和已陈述的先验知识，用于指导未来的课程。它们用于计算最近发展区。

## 模板

```md
# {学到的或确立的内容简述}

{1-3 句话：学到了什么（或确立了什么先验知识），以及为什么这对未来的课程重要。}
```

这就是全部格式。一条学习记录可以只是一个段落。价值在于记录"这现在已知"以及"这为何改变了下一步该教什么"——而不在于填满各个栏目。

## 可选栏目

仅在有真正价值时才包含。大多数记录不需要。

- **Status** frontmatter（`active | superseded by LR-NNNN`）——当先前的理解被证明是错的并被替代时有用。
- **Evidence**——用户如何展示理解（回答了一个问题、完成了一个练习、引用了过往经验）。当主张可能被重新审视时有用。
- **Implications**——这为未来课程解锁或排除了什么。当非显而易见时值得记录。

## 编号

扫描 `./learning-records/` 中最大的现有编号，加一。

## 何时创建学习记录

满足以下任一条件时创建：

1. **用户展示了对其非平凡内容的真正理解**——不是仅仅接触过，而是有证据表明他们能正确使用这个概念。这为下一步教什么设定了新的底线。
2. **用户披露了先验知识**——"我已经知道 X。" 记录下来，让未来课程不再重复教授。同时记录声称的掌握程度。
3. **一个误解被纠正**——用户之前相信了错误的东西，现在明白了为什么。这类记录价值很高：它们能预测相关主题未来的绊脚石。
4. **使命因学习而转变**——用户发现他们关心的事情与之前想的不同。交叉引用 [[MISSION.md]] 并更新它。

### 什么不算

- 仅仅被覆盖的内容。覆盖不是学习。等到有证据再说。
- 任何已在 [[GLOSSARY.md]] 中精炼捕获为术语定义的内容。不要重复。
- 逐次会话的活动日志。学习记录不是日记——它们是决策级别的洞察。

## 替代

当后续记录与先前记录矛盾时（用户的理解深化或纠正了），将旧记录标记为 `Status: superseded by LR-NNNN` 而非删除。理解如何演变的历史本身就是有用的信号。
