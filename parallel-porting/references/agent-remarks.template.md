## 回流规则

- **代码级差异** → 立即修（走正常合并），如"源默认值 ≠ 代码 switch default，以实际行为为准"。
- **工具链问题** → 修脚本（如执行器输出缓冲、超时提示 resume）。
- **待办** → 列入后续簇简报 + MODULES.tsv（如"OPT_MAP 缺键，语料无法覆盖某分支"）。
- 每轮结束检查登记册：无「未处置」条目（⏳ 必须在下轮处理或显式关闭）。
