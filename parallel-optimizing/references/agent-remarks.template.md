## 回流规则

- **行为等价差异**（bit-exact 覆盖下降/豁免超限/696 新增失败）→ 立即修（走正常合并），不允许带病合并。
- **性能反直觉**（bench 下降但代码看起来更优）→ 回退或单独调查，禁止「先合再说」。
- **豁免清单变更**（某模型变 bit-exact / 偏差超限 / 非 layered 判定漂移）→ 更新 triage-registry.json + 记录原因。
- **工具链问题** → 修脚本（如 check-bench-regression 缺失、执行器输出缓冲）。
- **待办** → 列入后续簇简报 + OPTIMIZATION_CLASSES.tsv（如「先验端口稳定性再决定缓存策略」）。
- 每轮结束检查登记册：无「未处置」条目（⏳ 必须在下轮处理或显式关闭）。
