# Bug Clarify — 修复前强制对齐

## 流程

用户说"修一下 XXX"或描述一个 bug 后，**必须**逐条确认以下 5 点，缺一不可。每点模糊就追问，不确定就列选项让用户选——不猜测。

1. **现象** — 具体看到了什么？错误信息/截图/日志？
2. **复现步骤** — 从哪一步开始、怎么操作、到哪一步出问题？
3. **预期行为** — 正确的行为应该是什么？
4. **严重性** — 阻断性？边缘 case？影响多少用户？
5. **回归风险** — 什么已有行为绝对不能变？附近有没有脆弱的逻辑？

**完成标志**：5 点均确认完毕，用 3 个要点总结给用户，用户回复"是"。

## 硬约束

确认完成前：不分析根因、不写修复方案、不写代码。
