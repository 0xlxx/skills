# API 设计指南

## 渐进式增强

API 应该对初学者极其友好，低门槛上手，但同时也必须具备高级特性，能够随着项目规模的增长而深入定制。

## 框架无关

API 不应该强绑定于某一个前端框架（如 Vue 或 React）。将逻辑层抽离成底层核心，再针对各个框架做轻量封装。

## 符合直觉的 DX

优秀的 API 必须提供极佳的开发者体验：自动补全、合理的默认值（零配置即可工作）、友好的 TypeScript 支持，减少开发者的心智负担。

## 原子化

设计细粒度、正交的 API，让开发者通过组合这些原子级 API 来实现复杂功能，而不是提供一个臃肿而封闭的巨型 API。
