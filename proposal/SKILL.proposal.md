# 自然心智模型

## 核心原则

**特化约束**是你发明的规则——你决定数值、你决定粒度、你决定过程。LLM 服从它是因为你说了，不是因为任务需要。

**自然心智约束**是从任务本质中推导出来的规则——它描述的是"做好这件事意味着什么"，LLM 凭自身判断力就能执行，因为它对齐的是结果而非过程。

优化一个 skill 的本质工作：逐行扫描，将特化约束替换为自然心智约束。

## 五类替换

### 1. 任意数值 → 原则性边界

特化约束给一个数字，自然心智约束给判断"够了"的标准。

| 特化约束 | 自然心智约束 |
|---|---|
| "拆成 2–5 个子概念" | "每个原子概念独立、完整、不需要上下文就能理解" |
| "至少一个例子" | "例子足以让抽象定义变成可触达的具体画面" |
| "至少一道练习" | "练习能检验用户是否真正理解了核心" |
| `minmax(..., 320px, ...)` | `var(--card-min, 320px)`——变量名编码意图，值是默认而非法律 |

**测试**：把数值拿走，LLM 还能不能判断该怎么做？能 → 数值是特化约束。不能 → 保留。

### 2. 分解动词 → 识别动词

"拆""切""分"预设了 LLM 要对概念施加一个分解动作。自然心智是：概念本身有层次，LLM 的工作是**识别**这个层次，不是**制造**它。

| 特化约束 | 自然心智约束 |
|---|---|
| "把概念拆成子概念" | "识别构成这个主题的原子概念" |
| "拆分" | "概念本身有层次——让这个层次可见" |
| "拆解" | "原子概念 / 递阶控制的下一层" |

**测试**：这个动词是在对概念做操作（拆、切、分），还是在让 LLM 观察概念本来的结构（识别、找出、确定）？前者 → 替换。

### 3. 规则无因果 → 规则有后果

每个规则应该让 LLM 理解违反的代价，而非记住一条禁令。

| 特化约束 | 自然心智约束 |
|---|---|
| "不设固定 width/height" | "固定尺寸 = 内容变了就崩" |
| "不先写 @media" | "断点是最后手段，不是第一反应" |
| "不写 $...$ 分隔符" | "HTML 特殊字符（& < > \\）会被浏览器转义" |

**测试**：把"不/禁止/不要"删掉，LLM 还会不会做正确的事？不会 → 规则缺因果。补上 WHY。

### 4. 魔数 → 命名意图

CSS 中的裸数值、步骤中的硬计数——都是你替 LLM 做的判断。用变量名或判断标准替代。

| 特化约束 | 自然心智约束 |
|---|---|
| `flex: 1 1 280px` | `flex: 1 1 var(--cmp-min, 280px)` + 注释"按内容自然宽度设" |
| "0001-<dash-case-name>" | 命名规则有理由（编号 = 顺序，dash-case = 文件名无空格） |

**测试**：数值本身是否编码了意图？否 → 用命名替代。

### 5. 过程指令 → 效果标准

告诉 LLM"做什么"而非"怎么做"。"怎么做"从任务本质中推导，"做什么"由完成标准检验。

| 特化约束 | 自然心智约束 |
|---|---|
| "至少一个具体例子" | "例子让本质从抽象变成可触达" |
| "包含 ① ② ③" | "读完后能说清它是什么、为什么存在" |
| "必须创建 prerequisite.html" | "前置摸底，有缺口才建 prerequisite.html" |

**测试**：把"怎么做"删掉，只保留"做到什么效果"，LLM 还能不能找到路径？能 → 过程指令是多余的。

## 执行

### Step 1: 扫描特化约束

逐行读 skill 文件（SKILL.md 及其 reference）。标记每一处：任意数值、分解动词、无因果的禁令、魔数、过程指令。

完成标志：每一处标记都能说出属于五个类别的哪一个——任意数值、分解动词、无因果的禁令、魔数、过程指令各归其位。

### Step 2: 替换

对每个标记点，问：这个约束是"任务本质要求"还是"你替 LLM 做的选择"？后者 → 用五类替换中的对应模式改写。

完成标志：每个标记点要么已替换，要么确认是必须保留的自然约束。

### Step 3: 验证

改写后的文件：删掉所有数值和禁令，LLM 仅凭对任务的理解就能做出正确判断——不需要记住你定的数或你写的流程。

完成标志：skill 不再依赖你替 LLM 做的选择。

## 不替换什么

有些约束看起来像特化约束，实际上是从任务本质推导的：

- **65ch 正文栏宽**——不是任意数值，是人眼扫读的生理上限
- **行高 1.6**——不是审美偏好，是长文本可读性的最低要求
- **data-latex 代替 $...$**——不是风格选择，是 HTML 转义的技术必然
- **prev/index/next 导航**——不是 UI 偏好，是多文件课程不迷路的必要条件

区别在于：删掉它，任务质量是否系统性下降？是 → 保留。
