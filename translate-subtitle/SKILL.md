# 字幕翻译：换语言，不换时间轴

难点不在翻译本身，在**单位**。逐行翻译会把句子拦腰截断，代词、语气、术语全崩。所以核心是：**先合并成语义块，整块翻，再按时间轴摊回去**。

## 步骤

1. **摸清输入。** 什么格式（srt / vtt / txt）、什么语言、多长、是人工字幕还是自动字幕。
   完成标志：知道有没有时间轴、是不是滚动式自动字幕——这两点决定后面要不要做去重和线性化。
2. **合并语义块。** 把碎句合成完整句子：句末标点、累计时长、累计字数任一到达阈值就断块。
   完成标志：块数远少于原始 cue 数（8 分钟视频通常 200+ 条 cue → 30~40 块），且每块是一句能读懂的话。
3. **建术语表。** 人名、产品名、专有名词、缩写，逐条定死译法。
   完成标志：一份「原文=译法」的清单；翻译时按引擎要求的形式喂进去。
4. **选引擎。** 本地（LM Studio + Hy-MT2）或 API（OpenRouter 等）都行，走 OpenAI 兼容接口。
   完成标志：端点能返回一句正确译文。引擎、模型、参数见 [`references/engines.md`](references/engines.md)。
5. **按块翻译。** 用引擎的**官方 prompt 模板**，不要自己发明指令。
   完成标志：每块译文都拿到了，且没有多余的解说、引号、原文残留。
6. **回写时间轴。** 译文按字符数比例摊回该块的时间跨度；单条超过字数上限就按标点切分。
   完成标志：时间轴单调递增、无重叠、无空条目，单条不超过约定字数。
7. **交付。** 目标语言字幕 + 可选双语版。
   完成标志：给出文件路径、条目数、时间轴校验结果（异常条数为 0），并说明术语表与残留不确定处。

脚本 [`scripts/translate_srt.py`](scripts/translate_srt.py) 覆盖第 2、5、6 步，支持字幕与文稿两种模式。

## 三个必须处理的字幕特性

**滚动重复。** 自动字幕会把同一句拆成多条、并重复上一行尾巴。不去重就直接翻，会出现整句重复。
**时间重叠。** 滚动显示时相邻 cue 的时间是重叠的（后一条在前一条还没结束时就开始）。不线性化的话，翻译重组后会出现**时间倒退**——字幕一闪一退。
**无标点长串。** 有些自动字幕整段没有标点，切分逻辑要有兜底（按空格、音符、标点逐级切），否则单条字幕会长到糊满屏幕。

这三条都在脚本里处理了：去重 → 线性化 → 分块 → 翻译 → 按标点/空格兜底切分 → 校验单调性。

## 用法

```bash
python3 scripts/translate_srt.py input.srt --out out.zh.srt \
  --engine hy-mt --model hy-mt2-1.8b \
  --base-url http://127.0.0.1:1234/v1 --api-key-env none \
  --terms "DNS=DNS,fake-ip=虚拟 IP" --max-chars 24 --bilingual
```

- `--dry-run` 只看分块结果，不花翻译成本
- `--mode text` 翻译纯文稿（块更大、无时间轴）
- `--bilingual` 输出中英对照
- 省略 `--base-url` 则用 `OPENROUTER_API_KEY` 走云端

## 校验口径

翻译质量看三件事，交付时逐条说明：

- **术语一致性**：同一个专名在全篇是不是同一个译法。
- **时间轴完整性**：条目数、单调性、有无空条目。
- **不确定处**：听写本身可疑、或译文有多解的地方，点名而不是抹平。
